# Snooze Button Roast

A one-line roast of an alarm clock ringing at 6am on a Saturday — my entry for the [make.fun bounty](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6).

> My alarm rang at 6am on Saturday like it had a job interview — I hit snooze and it got fired before breakfast.

## Run

```bash
python3 main.py
```

This writes the entry to `/output/entry.txt` (single line, no trailing newline) and validates it first: 1–200 characters, valid UTF-8, mentions `alarm`, `6am`, `Saturday`, and `snooze`. The program exits non-zero if any check fails.
